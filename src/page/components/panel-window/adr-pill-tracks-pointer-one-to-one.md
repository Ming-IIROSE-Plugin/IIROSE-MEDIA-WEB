# 胶囊拖动始终 1:1 跟手，粘连只表现在形状上

背景：贴边的胶囊要有「粘住边缘、拔掉」的蜂蜜般手感。最初用阻尼 / 追赶 / 橡皮筋式的位移来表现粘连，维护者试用后明确否决，原因是鼠标移得快时胶囊总是「慢一步」；后来发现的另一个滞后根因是落定过渡的 `left/top` 在断开时仍然开着。决定：拖动中胶囊位置永远等于指针位置（`getBoundingClientRect` 实测偏差 ≤ 2px），粘连只靠 SVG 颈的形状（先粗后急细、`DOCK_DETACH_PULL` = 56px 内断开、两端尖头各自缩回）表现，拖动中不开 `left/top/translate` 过渡，断开时只弹 `scale`。理由：跟手是硬要求，手感再好看也不能以滞后换取。来源：`epic-panel-dock` 的 12.5 票，提交 `71e9d04`、`376d714`；回归检查是 `scripts/verify/dock.mjs`（注入 `left/top` 过渡后该项报 FAIL，已验证）。
