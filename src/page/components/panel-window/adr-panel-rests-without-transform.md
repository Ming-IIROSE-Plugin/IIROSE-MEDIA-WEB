# 面板停稳时不带 transform / scale / translate

背景：点歌台的开合动画最初用容器的 `translate`（`--imw-dock-x/y`）加 `scale: 0.2` 从胶囊展开、缩回胶囊；12.8 票起改为只裁不缩（`panelGrow.ts` 写内联的 `clip-path` 和 `translate`，停稳后清掉），这条决定照样适用。决定：只有开合动画期间才有位移、缩放或裁切，打开停稳后计算值 `transform`、`scale`、`translate` 必须都是 `none`（写成 `scale: 1` 同样不行），`transform: none` 与 `scale: none` 也不能写进同一条规则。理由：带上任何 transform 都会让 `fixed` 子元素不再以视口为基准，`OrderMenu` 的坐标和菜单的 `fixed inset-0` 遮罩随之错位、点窗口外收不起来；而 lightningcss 会把同一规则里的 `transform: none` 和 `scale: none` 合并成 `transform: scale(1)`，悄悄破坏这一条，所以要拆成两条规则。来源：`epic-panel-dock` 的 12.2 票，提交 `0272a62`、`695db96`；约束写在 `src/app.css` 容器规则和 AGENTS.md 的 Known pitfalls。
