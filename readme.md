# 🎉 IIROSE-MEDIA-WEB

为 [蔷薇花园](https://iirose.com/) 打造的一站式媒体点播插件——搜索、点播、歌词，一气呵成。

## ✨ 功能特性

- 🎵 **多平台聚合**：网易云音乐、Bilibili 视频、无线电广播
- ⭐ **收藏**：网易云（单曲/专辑/歌单）和 B站视频一键收藏，左侧「收藏」页按来源和类型筛选、输入即过滤；可选端到端加密的云同步
- 🔍 **极速搜索**：关键词一搜，歌曲 / 专辑 / MV / 歌单即刻呈现
- 🎼 **歌词自动匹配**：点播即带歌词
- ⌨️ **快捷呼出**：点输入框上方的胶囊、按 Alt+S 或双指下滑，随时随地想点就点；也可以开成可拖动的窗口

## 📦 安装方法

### 💉 蔷薇注入

1. 打开左侧侧栏，选择「工具」>「终端」
2. 在终端中输入 `js` 回车，在框内输入以下地址并点击确定：

   ```
   https://func-ide-iirose-uest-web-cztvejindn.cn-beijing.fcapp.run/bundle.js
   ```

3. 等待载入成功后，呼出 UI：
   - 点聊天输入框左上方的胶囊（可拖动、可贴边收起）
   - **电脑端**：按下 `Alt + S`
   - **移动端**：双指下滑
   - 设置 →「插件设置」→「点歌台入口」可以只留其中一种
