# 侧栏开关行（sidebar-controls）

## 位置与结构

- 宿站左栏 `#functionHolderExtBox` → `.functionButtonGroup`（标题已由 `SidebarMediaEntry` 改为 `IIROSE-MEDIA-WEB`）。
- 现有「播放进度」入口 `#imw-media-progress-entry` 是 `#shareMediaBox` 所在 `.functionButtonExt` 的后继兄弟。新增的开关行插在该入口之后，独占一行：一个容器 `#imw-playback-controls`（`display:flex; width:100%`），内含若干等分按钮。
- 容器只注册按钮数据（`id`、图标、标签、可用性求值、可用性原因、点击回调），渲染层遍历生成。后续新增按钮只需追加一条注册项，不改布局代码。

## 按钮

| id | 标签 | 语义 |
| --- | --- | --- |
| `imw-toggle-loop` | 单曲循环 | 点亮 = 当前曲目循环 |
| `imw-toggle-shuffle` | 收藏随机 | 熄灭态点击 = 弹出选择面板，确认后点亮；点亮 = 在选定范围内随机续播 |

- 互斥单选：点亮其一自动熄灭另一；再次点击熄灭。
- 随机的点亮必须经过面板（`shuffle-picker-panel.md`）：熄灭态点击只开面板不改状态；面板确认才点亮并熄灭循环，取消则两个按钮都保持原状。点亮态点击直接熄灭，不开面板（自动转入待命时的首次点按例外，见下表）。
- 面板打开期间再点侧栏随机按钮：不重复开面板，只把焦点移回面板。
- 点亮态：图标与文字使用强调色 + 底色加深 + `aria-pressed="true"`；熄灭态：常规前景色 + `aria-pressed="false"`。两态在浅色与深色侧栏都需可辨（沿用 `SidebarMediaEntry` 的 `isDarkSidebar` 判定与 `data-imw-theme`）。
- 触控目标不小于 44×44；移动断点 `max-[768px]` 下按钮等高、无 gap，文字沿用 13px 级别，不换行。
- 图标自包含：SVG（循环箭头 / 打乱箭头）或 `#id::before` + `font-family:"md"`，禁止借用宿站 `mdi-*`。

## 可用性与禁用原因

随机不可用时点击只报原因，不弹面板。

按钮不可用（视觉灰化 + `aria-disabled="true"` + 点击 `ShowMessage` 报原因）的情况与文案：

| 条件 | 文案 |
| --- | --- |
| 无当前媒体或时长为 0/未知 | 直播或时间未知，无法使用 |
| 连接未就绪或已断开 | 连接未就绪或已断开，暂时无法调整 |
| 循环：非本人点播且无静默权限 | 无媒体管理权限，且该曲目不由插件点播，无法循环 |（本人点播但缓存丢失时不再禁用，改走本地 seek 兜底）
| 随机：所有平台都没有收藏 | 收藏为空，先去收藏一些内容 |
| 随机：点亮期间选择范围全部失效 | 随机范围为空，重新选择（熄灭） |
| 循环/随机：当前曲目由他人点播 | 不显示为禁用，保持原状态待命（见 ownership-and-lifecycle.md）：点亮视觉不变，以 `title` 与读屏状态区说明「当前曲目由他人点播，暂不自动续播」；亲手点亮（循环点击 / 随机面板确认）后若当下即待命，当场提示一次原因，再点即熄灭；自动转入待命的，首次点按只弹原因不切换，再点才熄灭（触屏/键盘可达） |

前两行（无媒体 / 连接）由 story 1 实现，待命由 story 2 实现；其余原因的行由对应 story 通过 `PlaybackMode.setAvailability` 接入，在接入前按钮不会因这些条件禁用。

换房不属于「转为不可用」：房间标识变化时开关**熄灭**并提示一次「已切换房间，播放模式已关闭」，按钮随后回到熄灭态（不灰化、不缺席）。

- 已点亮但条件转为不可用（换房、媒体消失、断线）时：先熄灭并提示一次原因，不保留「亮着但不工作」的状态。
- 不可用不等于熄灭语义混淆：不可用由 `aria-disabled="true"` 表达（保持可聚焦可点击以便报原因），点亮由 `aria-pressed` 表达；不可用时 `aria-pressed` 恒为 `false`。

## 幂等与清理

- 复用 `SidebarMediaEntry` 的 MutationObserver 适配节流：侧栏重建、折叠展开后重新插入容器；已存在则只更新状态，不重建节点。
- 侧栏折叠时按钮行的 DOM 是否保留由图层的幂等重建吸收，不作为验收条件：折叠、展开、重建三种情况都只允许出现一个容器。
- 卸载（插件关闭/热更新）时移除容器、监听与定时器，恢复宿站原状。
- 重复注入产生的第二实例不得重复插入容器（见 ownership-and-lifecycle.md）。

## 反馈

- 自动动作失败只提示一次（复用 `ShowMessage`），不做逐次刷屏；同一原因 10 秒内去重，与网易云批量失败的既有约定一致。
- 成功时不提示，只靠宿站播放状态与按钮点亮态表达。
