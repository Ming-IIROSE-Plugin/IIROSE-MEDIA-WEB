# 随机选择面板（shuffle-picker-panel）

CAP-8/9/10 的视觉与交互契约。本面板是插件浮窗的视觉基准：外框、头部、按钮、配色与焦点环抽在共享模块 `src/page/components/floating-panel/`，「播放进度」浮窗（`MediaProgress.tsx`）引用同一模块（SPEC-sidebar-media-progress CAP-6），两块面板看起来出自同一处。

## 挂载与层级

- 独立根节点 `#imw-shuffle-picker-root`，挂在 `messages.html` 的 `body` 下，不进主面板 `.IIROSE_MEDIA_CONTAINER`：主面板关着时也能弹出。
- 只有面板、没有遮罩（非模态），面板 `z-index` 高于播放进度浮窗（`90001`），根节点本身不拦截面板外的指针事件；同页只允许一个根节点，重复注入时由新实例接管旧根节点（与主面板同一单例规则）。
- `app.css` 只为该根补 `box-sizing: border-box` 兜底（与 `#imw-media-progress-root` 同列），其余样式全部写 Tailwind 类。

## 视觉规范

| Token | 浅色 | 深色 |
| --- | --- | --- |
| 面板底色 / 文字 | `bg-[#fafbfe]` / `text-[#253047]` | `bg-[#242a34]` / `text-[#f4f6fa]` |
| 描边 | `border-black/10` | `border-white/15` |
| 强调色 | `sky-500`（勾选、主按钮、分段选中、三态部分勾） | 同左 |
| 行悬停 / 按压 | `hov:bg-sky-500/8`；按压 `bg-sky-500/15` | 同左 |
| 次要文字 | `opacity-65`，12px | 同左 |
| 阴影 | `shadow-[0_12px_40px_rgba(0,0,0,0.25)]` | 同左 |

- 深浅主题与播放进度浮窗同一判定：宿站 `window.theme` 为假值即深色（`HostMediaBridge` 的 `dark`）。
- 主按钮：`bg-sky-500 text-white rounded-lg font-semibold`；不可点时 `opacity-40`，并在按钮下方显示原因「至少选择一首」。
- 次要按钮：透明底 + 描边，同圆角。
- 字号：标题 15px，行标题 14px 单行省略，副行 12px；数字用 `tabular-nums`。

## 列表行

| 行类型 | 内容（左 → 右） | 行高 |
| --- | --- | --- |
| 单曲 / 视频 | 复选框 · 封面 40×40 `rounded-lg` · 标题 / 「作者 · 单曲｜视频」 | 56px |
| 歌单 / 专辑 | 三态复选框 · 封面 · 标题 / 「N 首 · 歌单｜专辑」，部分勾选时附「· 已选 k」· 展开钮 44×44（`›` 旋转为 `⌄`） | 56px |
| 展开的曲目 | 缩进 52px · 复选框 · 曲名 / 歌手（无封面，减少图片请求） | 44px |

- 整行可点：点行 = 切换勾选；展开钮独立，点它只展开/收起，不改勾选。
- 三态：全勾 = 整单（动态范围）；部分 = 固定曲目集合；未勾。点三态框在「全勾 ↔ 未勾」间切换；只能通过展开后逐首勾选进入「部分」。
- 展开后逐首勾满全部曲目时，自动转为「整单」。
- 复选框自绘：20×20 `rounded-md`，勾选态强调色底 + 白色 SVG 勾，部分态强调色底 + 白横线；外层点击区 44×44。
- 封面：`http://` 先升级为 `https://`；`onerror` 回退到自包含音符/视频 SVG（强调色 15% 底）。
- 长标题 `truncate` 出「…」，文本容器 `min-w-0`。

## 平台标签

- 只显示有收藏的平台，另加已存随机平台（即使其收藏已删光）；只剩一个平台时不显示标签行。初始标签：已存随机平台 → 无记录时 `defaultPage` 对应平台（有收藏才用）→ 第一个有收藏的平台。
- 数量自适应：1～3 个等宽分段控件（圆角按首尾自动加）；4 个及以上改为可横向滑动的胶囊标签（按文字宽度，高 44px，`overflow-x-auto`，右缘渐隐提示更多，选中项 `scrollIntoView` 到可见区）。
- `role="tablist"` + `aria-orientation="horizontal"`，左右键与 Home/End 切换；切换即读取该平台收藏与已存选择，各标签本次未保存的勾选、展开与权重在面板打开期间保留。
- 搜索词切换标签时清空。
- 没有收藏的平台：列表区居中「该平台还没有收藏」，主按钮不可点。
- 确认：保存所有本次改动过的平台选择，以当前标签为随机平台；摘要只统计当前标签。

## 搜索

- 输入即过滤（150ms 防抖），不区分大小写，匹配收藏行的标题与作者；已展开且已加载的歌单内同时过滤曲目（曲名/歌手），歌单自身不匹配但有曲目命中时保留该歌单行。
- 未展开、未加载的歌单不为搜索去拉详情。
- 搜索只影响显示，不改变勾选；被过滤掉的已勾选项仍计入底栏摘要与最终选择。
- 「全选」「全不选」只作用于当前可见行；搜索为空时等于全部。
- 无结果：列表区居中显示「没有匹配的收藏」+「清除搜索」文字钮。
- 搜索词不持久化，每次打开面板为空。

## 展开加载

- 首次展开时才拉详情（网易云经 `SendFetch.neteaseRequest`），会话内按收藏 id 缓存。
- 加载中：展开区显示 3 行骨架（高 44px，`animate-pulse` 灰条），展开钮换成转圈图标。
- 失败：展开区显示一行「加载失败」+「重试」文字钮；该行的整条勾选不受影响，可照常确认。
- 空歌单：展开区一行「歌单里没有可播放的曲目」，该行复选框置灰。

## 权重分段控件

- 两段：「按条目」「按歌曲」，`role="radiogroup"`，选中段 `bg-sky-500 text-white`，容器 `rounded-lg` 描边，每段高 32px、外层点击区 44px。
- 控件下方（或移动端工具条下）一行 11px 说明，随选中段切换：「每个收藏机会相同」/「每首歌机会相同，大歌单出现更多」。

## 底栏摘要

- 「已选 X 条 · 约 Y 首」：X = 选择项数；Y = 单曲数 + 整单 `trackCount` 之和 + 部分勾选数；`trackCount` 缺失时显示「约」并按已知数计。
- 未选任何项：摘要显示「未选择」，主按钮不可点。

## 交互流程

- 打开：侧栏随机按钮在熄灭态被点击。预填上次确认的选择与权重（CAP-10）；首次默认全部整条勾选、权重「按条目」；上次确认后新增的收藏显示为未勾选。
- 确认「开始随机」：保存选择 → 关闭面板 → 点亮随机（熄灭循环）。若此时房间在放他人曲目，按待命规则当场提示一次。
- 取消：「取消」按钮、头部 ✕、`Esc`（焦点在面板内）、移动端系统返回均等价，不保存改动、不改变任何开关。面板非模态：没有遮罩，点面板外不关闭，外部的点击、输入、滚动全部交给宿站。
- 面板内的鼠标按下/抬起与触摸不冒泡到宿站：宿站在 `document` 上用 mousedown→mouseup 识别滑动手势（右滑返回、左滑捷径等），面板内的拖动不得被它识别。
- 层级：面板 `z-index` 90010，高于插件主面板（90000），低于宿站弹窗与提示层（9999999），宿站弹出的选择框/提示总在面板之上。
- 系统返回的实现：宿站以 `onpopstate` → `Utils.backward()` 实现返回（并自行补回 `"forward"` 历史条目）。面板打开期间接管 `Utils.backward`：返回只关面板、不执行宿站返回；面板关闭后原样交还。插件不读写浏览历史，✕/取消/Esc/确认都不会触发宿站返回。宿站没有 `Utils.backward` 时返回键不关面板。
- 打开期间收藏被增删：列表不实时刷新；确认时与当前收藏对齐，已删除的项丢弃。
- 打开期间换房或断线：面板保持，确认时若随机不可用则报原因、不点亮。

## 拖动与位置记忆

- 拖动手柄：头部（图标、标题、空白处）与移动端顶部拖拽条；关闭钮、标签、搜索框等可交互元素不触发拖动。`touch-none` 只加在手柄上，列表照常滚动。
- 拖动中光标 `cursor-grabbing`，手柄常态 `cursor-grab`；松手即保存位置。
- 位置存 `localStorage` 键 `imwShufflePickerPosition`（`{x,y}`，不分账号），读写失败不影响使用。
- 约束：复用播放进度浮窗的 `constrainPosition` 与视口缩放换算，四边留 12px；打开时与窗口尺寸变化时都把已存位置收回视口内。
- 无已存位置：桌面居中卡片；移动端浮动卡片停在视口上半部（不挡底部聊天输入栏）。有已存位置：移动端也作浮动卡片（宽度不超过视口减 24px），入场改为淡入 + `scale-95→100`。

## 动效

- 打开：卡片（桌面与移动端）`scale-95 → 100` + 淡入 180ms，`ease-out`。关闭为反向，时长减半。
- 展开/收起：展开钮旋转 90° 120ms；内容区高度不做动画（避免长歌单卡顿），直接出现。
- `.IIROSE_MEDIA_CONTAINER *` 的全局 `transition: all .5s` 不覆盖本根（独立根节点）；仍需快反馈的按压态用 `duration-N!`。
- `prefers-reduced-motion: reduce` 时全部去掉位移，只保留淡入。

## 可访问性

- 面板 `role="dialog" aria-labelledby` 指向标题（非模态，不设 `aria-modal`）；打开时焦点移到搜索框（移动端不自动聚焦，避免弹出键盘遮挡列表）；`Tab` 不锁在面板内，可移到宿站；关闭后焦点还给侧栏随机按钮（焦点已在宿站其他元素上时不抢回）。
- 复选框 `role="checkbox"` + `aria-checked="true|false|mixed"`；展开钮 `aria-expanded` + `aria-controls`。
- 列表的键盘：`Space` 切勾选，`Enter` 在展开钮上展开；所有可点元素 `focus-visible` 时显示 2px 强调色描边。

## 验收清单（视觉）

- 400×800 与 1280×720 视口各开一次：无横向滚动（`scrollWidth - clientWidth ≤ 0`），底栏按钮不被裁切，长列表只在列表区滚动。
- 超长标题出现「…」；歌单 100+ 首展开后滚动流畅、底栏始终可见。
- 触屏点一下行后无粘滞高亮（`hov:` 门控）。
- 浅色、深色侧栏下文字与勾选态对比清晰。
