- (decision) 私聊误发根因已定位：changedOriginalMoveInputDo 声明为 async 返回 Promise(truthy)，导致宿站 if (pmFull && !Utils.service.moveinputDo(this.value, 1)) 判断为假而执行 msgfetch 私聊外发；修复为同步拦截函数，命中@时同步返回 falsy，后台异步执行解析与点播
- (capability) CAP-1 用户在公屏或私聊输入框输入@指令（链接点播或媒体搜索）时，均能拦截该行为并阻止文本作为聊天消息发出，同时清空输入框并执行对应功能
- (capability) CAP-2 用户输入网易云单曲、专辑、歌单的长链、短链或客户端分享文本（含杂项参数与中文说明）时，插件自动解析对应 ID 并发起点播（单曲直接点播，歌单/专辑支持正序/乱序或选集点播）
- (capability) CAP-3 用户输入B站视频长链（含无协议前缀）、b23.tv短链或客户端分享文本时，插件自动解析BVID并点播；对多P视频支持根据p参数直达指定分P或弹出选集点播
- (capability) CAP-4 用户输入音视频媒体直链时，插件尝试嗅探媒体元数据并创建媒体卡片点播；若无法嗅探或非媒体链接，放行至宿站原生逻辑处理，不报错不中断
- (capability) CAP-5 用户输入@歌曲名称（非URL文本）时，插件呼出媒体窗口并将关键词填入搜索框触发检索，且在私聊与公屏下均不发送该文本
- (constraint) 代理方法必须保持同步调用契约，严禁返回 Promise 给宿站，命中@拦截必须同步返回 false/undefined
- (constraint) 短链重定向请求（b23.tv、163cn.tv）必须走 CORS 代理（如 Tencent SCF 代理）解析 302 响应头 Location 或响应体，禁止宿站域直连导致跨域失败
- (constraint) URL提取必须基于正则匹配分享文案中的实际链接子串并自动补齐缺少协议的链接（如 bilibili.com/... 补全 https://），禁止直接对整体输入做 new URL()
- (constraint) 未命中插件拦截能力的输入，必须透传原始参数 (e, t) 调用备份的原始 moveinputDo，保持宿站原生快捷指令与弹幕逻辑完好
