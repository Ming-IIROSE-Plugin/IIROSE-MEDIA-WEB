# 插件主面板「点歌台 Media Desk」重新设计

## Description

愿景驱动：插件主面板要成为房间里的一张「点歌单」——几秒内把歌或视频送进房间，其余时间安静退场。现行面板是旧四行顶栏（导航、工具栏、平台、分类）叠前轮浮窗配色，平台是一整行、搜索不是主角、选集依赖宿站 `buildSelect2`（受淡出冲突与点选顺序丢失困扰）、没有点播历史。维护者已定稿新的视觉与行为规格（纸/墨/蔷薇红、竖栏 + 宽搜索栏 + 曲目表 + 底部「Now in room」条），授权推翻宿站风格与现有布局约定，但所有现有功能必须保留。受影响的是在蔷薇花园房间里点歌的桌面与手机用户。

## Outcome

- 在真站（iirose.com 视频分享房）以 1280×720 与 400×800、宿站浅色与深色四种组合打开点歌台：J1–J5 五条旅程（EXPERIENCE Key Flows）都能走到高潮——底部条/迷你条切到所点媒体、房间出现点播卡片（以聊天区 `div.msgholderBox` DOM 判定）；选集面板按点选顺序播放；两个浮窗与主面板并排视觉同源；brownfield.md「必须存活」清单逐项可演示，`npm test` 与 `npm run build` 通过。

## Requirements

1. R1 (CAP-1): 主面板、两个浮窗、选集面板与批量进度浮窗共用一套纸/墨/蔷薇红视觉令牌（浅深两套、焦点环、五档圆角），来源唯一。 — 成功标准:DESIGN.md frontmatter 的每个颜色键（含 `-dark`）在共享模块中有对应令牌；组件代码中不再出现 `themed*`、平台品牌强调色或裸写的颜色/`rgba`；宿站浅色与深色下各界面取色与 DESIGN.md 一致，对比度表中的组合实测达标；数字（时长、序号、页码）用系统界面字体 + 等宽数字特性，不用等宽字体栈。
2. R2 (CAP-2): 用户在桌面竖栏或手机底部标签栏切换音乐、视频、电台、收藏、设置、关于（手机关于并入设置）六种模式，页头显示当前模式名。 — 成功标准:桌面 >768px 显示 84px 竖栏 + 页头（眉题、宋体标题、关闭钮），手机 `max-[768px]` 显示五项底部标签栏；单击即切换，选中项样式与 `aria-current` 正确；各模式各自保留关键词、范围与页码；重新打开面板恢复上次状态、首次打开进入「插件启动默认页面」设置指定的模式。
3. R3 (CAP-3): 用户在页头宽搜索栏内选来源、输入并提交搜索；粘贴 BV 号或链接即自动识别提交。 — 成功标准:搜索栏含来源切换器（带来源圆点；点开是插件自有下拉菜单，不用原生 select，当前项打勾，上下键/回车操作，`Esc` 与返回键只关菜单）、输入区（蔷薇红光标）、键位提示（未聚焦且空为 `/`，聚焦且空不显示，有内容为 `Enter`；与「搜索」按钮留出间距）与「搜索」按钮（手机仅来源简称 + 输入区，字号 16px）；Enter 或按钮提交；桌面打开即聚焦、手机不自动聚焦；音乐模式粘贴视频链接自动切到视频模式再提交；收藏与电台模式为即输即滤、不发请求。
4. R4 (CAP-4): 用户用范围标签、视图切换与分页浏览结果。 — 成功标准:范围标签单选（音乐：单曲/专辑/歌单/MV；视频：推荐/视频/直播；电台：地区；收藏：全部/单曲/歌单与专辑/视频），选中附结果数；切换范围或来源页码归 1、滚到顶部并按当前关键词重取；视图切换常驻范围行、分页不因它跳动：音乐单曲（含首屏「最近点播」）、视频、收藏、专辑/歌单内页可切列表/网格，专辑/歌单与电台只有列表、MV 只有网格，这些范围里切换仍在原位、灰色锁定并提示「这里只有列表/网格视图」；分页为上一页/下一页 + 等宽 `01 / 28`，无无限滚动；手机标签区可横向滚动、视图切换与分页固定在右侧。
5. R5 (CAP-5): 用户在曲目表、音乐网格、视频网格与专辑/歌单内页中看清结果并一键点播。 — 成功标准:曲目表桌面七列、手机五列（含 40px 收藏星），悬停（仅 `hov:`）整行高亮、点播按钮转实心，行底线与表头线左右对齐；正在播放项显示音柱 + 蔷薇红标题 + 文字后缀；视频卡 16:9（MV 同、直播换「直播」徽章），音乐网格卡 1:1；无悬停设备（手机、iPad 横屏）「点一下选中、再点按钮点播」，键盘 `:focus-within` 同样显示按钮；专辑/歌单行桌面只有封面、标题与「≡ 查看」三处进入面板内曲目列表（整行可点会让收藏星难以点中），手机整行点按进入；「‹ 返回」/`Esc`/宿站返回键回到原结果并保留关键词、页码与滚动位置；内页头含视图切换，「全部播放」（只在按钮自身悬停时转实心）先在插件自有菜单选「正序播放 / 乱序播放」再按所选顺序点播整张列表（批量播报，与现有整单点播结果一致），取消选择不点播；加载为静态骨架，无结果、过滤无结果、加载失败 +「重试」按 EXPERIENCE State Patterns；房间不支持点播时所有点播入口灰化且点击提示「这个房间不支持点播」。
6. R6 (CAP-6): 面板打开时，用户在底部条（桌面）或迷你条与展开的底部条（手机）看到房间正在放什么、谁点的、进度，并切换单曲循环/收藏随机。 — 成功标准:显示封面、标题、「某某 点播」（本人为「由你点播」）、进度；有媒体权限或本人点播时进度可点击/拖动跳转（复用现有跳转逻辑），否则只读；直播/电台流显示「直播」+ 已播时长且不可跳转；无播放显示「房间暂时安静」并保留开关；模式开关与播放进度浮窗为同一状态（互斥、待命、随机先弹选择面板）；手机点迷你条主体展开三行完整底部条（从底部升起、收起时滑出再卸载，模式开关为柔和胶囊），房间无播放时不展开；桌面底部条是与面板同色的贴底细栏，设置与关于页桌面不显示（手机迷你条保留）。
7. R7 (CAP-7): 手机用户直接在曲目行与卡片上收藏和点播，不再经过弹层。 — 成功标准:手机曲目行五列：封面 / 标题 / 时长 / 40px 收藏星 / 40px 点播钮，两钮并排、点击区 ≥44px，点行体无动作；音乐与视频卡首次点按显示「点播」胶囊、再点胶囊点播，卡片收藏星 32px（点击区 44px，保证三列窄卡的标题与时长可读）；课程卡「选集」钮手机也显示；多 P 视频点播时仍弹出选集面板；列表行内不堆其他按钮。（取代原「手机操作条」；操作条已取消，ID 沿用。）
8. R8 (CAP-8): 用户在插件自有的选集面板中按点选顺序多选分 P / 分集，选正序或乱序后点播，完全不经宿站 `buildSelect2`。 — 成功标准:多 P 视频与多集剧集点播时打开面板（桌面居中卡片、手机底部抽屉，层级同收藏随机面板；网易云歌单以 `trackIds` 为完整曲目列表，详情 `tracks` 不全时分批补取，千首歌单也完整可选；万首歌单立即列出全部、歌名在后台并发补全并显示进度，列表分批渲染，关面板中止补取）；点选显示序号徽章 1、2、3…，取消某项后其后序号前移；「全选」按列表顺序选中全部（徽章 1…N），全部选中时再点为取消全选；默认正序，全选后正序/乱序照常生效；未选时「点播所选」禁用；确认后实际播放顺序等于点选顺序（乱序时为随机）；关闭钮、点外侧、`Esc`、宿站返回键 = 取消不点播；加载中骨架、0 集与加载失败 +「重试」按 State Patterns；选中项读屏读出「第 N 个」。
9. R9 (CAP-9): 用户在收藏模式过滤并点播全部平台的本地收藏，在电台模式按地区浏览并一键点播电台。 — 成功标准:收藏模式取代旧「全网/收藏」切换：来源切换器为全部/网易云/B站，范围为类型，输入即按标题/歌手/作者过滤（不区分大小写、不发请求），可切列表/方形卡网格，出处列为来源圆点 + 平台简称（歌单/专辑显示「网易云-歌单」等类型）；收藏里的专辑与歌单与搜索结果同一种行/卡（曲目数 + 「查看」进内页）；每页条数由设置「收藏每页显示」决定；在收藏模式取消收藏后该行保留到离开模式、切换范围/来源或改过滤词；电台模式地区标签默认第一个、输入即过滤台名、不分页。
10. R10 (CAP-10): 用户打开音乐模式未搜索时看到自己最近点播过的音乐，可直接再点。 — 成功标准:每次插件成功发出点播（曲目行、网格卡、收藏、电台、视频、选集、`@` 链接拦截）写入一条本机 localStorage 记录，同一媒体移到最前、最多 50 条、不分房间、不进云同步；音乐首屏列出音乐来源条目（可切列表/网格），标题「最近点播」；无记录显示「还没有点播记录。搜索歌名或歌手，点播到房间。」；从首屏点播不重复计数；刷新页面后仍在。
11. R11 (CAP-11): 用户在新外观的设置页与关于页查看并修改全部现有设置、使用全部现有关于条目。 — 成功标准:设置按现有平台分组作范围标签（手机末项为「关于」；插件设置含「收藏每页显示」10/50/100/自定义 1–500、默认 10），每个子分组一张设置组卡；取值类行显示当前值 + chev，点整行调用现有设置动作，确认后即时生效、无「保存」；开关类为 `role="switch"` 开关，需额外流程的（云同步启用）流程完成后才显示为开；动作类、只读类行为按 EXPERIENCE；关于卡四项及其动作不变，外链用图标不用 emoji；现有设置项一项不少。
12. R12 (CAP-12): 播放进度浮窗与收藏随机选择面板与主面板视觉同源。 — 成功标准:两个浮窗外框、头部、按钮、分段、开关、勾选、焦点环改用新令牌（sheet 底、ink 字、rule 描边、`xl` 圆角、蔷薇红强调），不再出现天蓝；结构、拖动、位置记忆、行为与各自既有规格一致，既有测试保持通过。
13. R13 (CAP-13): 后续 dev agent 读 AGENTS.md 时得到与本规格一致的约定。 — 成功标准:AGENTS.md 中「主面板颜色一律取 floating-panel 的 `themed*` 令牌」与「顶栏布局与触控目标约定（Row 1–4）」被删除并改写为新令牌来源、新布局（竖栏/标签栏、搜索栏、范围行、底部条）与「选集不再走 `buildSelect2`」等约定；保留 44px 触控与 `max-[768px]`；该改写与第一个主面板 story 在同一轮提交。
14. R14 (CAP-14): 键盘与读屏用户能完整操作点歌台，`Esc` 与宿站返回键按层逐级关闭。 — 成功标准:`Alt+S` 打开并聚焦搜索栏，`/` 聚焦搜索栏；关闭顺序为 选集面板/收藏随机面板 > 展开的底部条/「全部播放」顺序菜单/来源菜单（互斥） > 专辑/歌单内页 > 主面板，每次只关一层；浮层打开时焦点移入并循环、关闭后归还触发元素；Tab 顺序、`role`（tablist、radiogroup、dialog、checkbox、switch、slider）与 `aria-label` 按 EXPERIENCE Accessibility Floor；可调进度轨方向键 5 秒、`Shift` 30 秒；`:focus-visible` 显示焦点环；`prefers-reduced-motion` 去掉位移动画。
15. R15 (CAP-15): 用户点播后立刻看到反馈，连点不会重复发送刷屏。 — 成功标准:所有手动点播入口（曲目行、网格卡、视频卡、收藏、最近点播、电台、「全部播放」选定顺序后）共用一个守卫：同一条目点播进行中再点无效；按钮原地显示「点播中」转圈，直到第一条 `&1` 点播报文真正发出即恢复可点（无冷却、无「已点播」态）；平台提示失败 → 「重试」并轻晃；弹出选集面板或顺序菜单不算失败、按钮安静复原；电台至少转圈 1 秒；发出后面板底部浮出提示条「已点播《…》」约 2 秒；整张歌单在第一首发出时即解锁。
16. R16 (CAP-16): 整张正序/乱序与选集多选这类长批量点播可见进度、可中途停止。 — 成功标准:开始批量时在页面右下角（桌面在底部条上方）弹出进度卡：「正在点播《…》」+ 进度条 + 已发/总数 + 「停止」；卡挂在页面 body 独立根，关闭点歌台面板后仍在；点「停止」后不再发下一首（含取歌词期间）、卡显示「已停止」并在约 1.2 秒后淡出，正常播完停留约 4 秒后淡出，× 可立即关闭；准备阶段显示不确定进度；减少动态效果时关闭动画。

## Constraints

- 保留全部现有功能与入口：搜索、分页、点播与播报档位、收藏与云同步、全部设置项、关于动作、`Alt+S`、双指下滑、侧栏进度入口与侧栏播放行、输入框 `@` 链接拦截；可推翻的只有外观与布局（清单见 brownfield.md）。
- 插件运行在 `messages.html` iframe 内（1.13–1.19 倍缩放）：手机布局一律 `max-[768px]`，不得依赖更窄断点；手机点击区 ≥44px（视觉可更小），手机搜索字号 16px。
- 层级固定：主面板 90000、播放进度浮窗 90001、收藏随机面板与选集面板 90010；宿站弹窗与提示层 9999999 永远在上，点歌台不得假设自己在最上层；展开的底部条与顺序/来源菜单挂在主面板内部，不另设 z-index 根；批量进度浮窗独立根 90008。
- 只用 Tailwind 任意值类 + `imw-dark:` / `hov:` 变体；不新增 SCSS、不新增依赖、不加载网络字体；`src/app.css` 只放 Tailwind 无法表达的内容。
- 令牌唯一来源在 `src/page/components/floating-panel/` 模块；组件不裸写颜色与 `rgba`，不另写配色。
- 动效：`src/app.css` base 层只给默认过渡（颜色/透明度/阴影/缩放，120ms，三档时长与统一缓动），不得再有通配 `transition: all`；按下反馈统一用 `deskPress`；`prefers-reduced-motion` 时去掉缩放与位移动画。
- 插件不带 Tailwind preflight：`border-solid` 加单边边框会让其余三边落到默认 3px，边框基线由 base 层补（`border: 0 solid currentcolor`）。
- 图标一律自包含内联 SVG（`currentColor`）；不借用宿站 `mdi-*` 类，不用 emoji。
- 封面与缩略图先 `http://`→`https://` 升级并挂 `onerror` 回退 thumb 底 + 图标；裁切填满不留黑边。
- 主题跟随宿站 `window.theme`，面板每次打开写 `data-imw-theme`；无独立主题开关。
- 宿站返回键经接管 `Utils.backward` 逐层关闭（与收藏随机面板同一机制），不读写浏览历史；面板内拖动、滚动不得冒泡被宿站手势识别。
- 选集面板必须保留有序多选语义：确认结果为点选顺序数组，业务层（网易云批量详情、B 站分 P、多源剧集）按此顺序重排；单项走单曲播报窗口、多项走批量播报（沿用 `Announce.runSingleAnnounce` / `runBatchAnnounce`）。
- 进度跳转复用现有逻辑与权限判定；模式开关规则沿用 spec-playback-loop-shuffle，不得新增第二个自动播放控制器。
- 网易云请求一律经 `SendFetch.neteaseRequest`；失败提示走宿站 `ShowMessage.show`、同因 10 秒内只提示一次；成功确认只用面板内提示条与按钮状态，不弹宿站提示。
- 测试文件不写 JSX；每个 story `npm test` 与 `npm run build` 通过后提交并推送 `origin main`；格式化不与功能改动混提。

## Done when

## Boundaries

- 不加载网络字体，不提供独立主题开关、第三套主题或平台品牌色主题。
- 不做无限滚动；不新增平台或关于条目（设置项仅新增「收藏每页显示」）。
- 不改单曲循环、收藏随机、播报档位、云同步的业务规则，只换入口外观。
- 不改宿站界面、宿站弹窗与宿站提示层外观；设置取值类沿用的宿站选择弹窗不重做；面板内自有提示条只确认点播，不替代宿站的失败提示。
- 最近点播不进云同步、不分房间、不提供删除或管理界面。
- 本轮不改侧栏播放行与侧栏进度入口的外观。
