# 收藏系统信息架构与导航规范 (navigation-and-ia.md)

## 1. 导航层级总览与视觉布局 (4-Row Hierarchy)

IIROSE-MEDIA-WEB 保持极致优雅的四层顶栏结构。本设计不破坏原有 Row 1「音乐 vs 视频」的最高级媒介分离，而是将「收藏」作为**视界模式（Mode Toggle）**集成于 Row 2 工具栏，支持**点亮（激活收藏模式）与点暗（正常发现模式）**无缝双态切换。

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ Row 1 (大类导航): [返回] [IIROSE-MEDIA]                   [音乐] [视频] [设置] [关于]    │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ Row 2 (工具栏):   [卡片/列表] [⭐收藏模式]  [🔍 搜索框]      [xx/xx]  [上一页] [下一页]   │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ Row 3 (平台选择): [网易云音乐]   [JOOX]   [无线电广播]  (音乐下) / [哔哩哔哩] (视频下)    │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ Row 4 (形态联动): [全部]   [单曲]   [专辑]   [歌单] (网易云收藏态) / [搜索音乐] (发现态) │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

---

## 2. 各层级交互行为定义

### 2.1 Row 1: 一级主导航 (`MainNavigationBar`)
- **保持现状，音视频绝对隔离**：
  - 音乐（Category 0）：收纳所有音频平台（网易云、JOOX、电台）；
  - 视频（Category 1）：收纳所有视听平台（哔哩哔哩、多源剧集）；
  - 设置（Category 2）与关于（Category 3）。
- **零顶栏膨胀**：移动端保持既有的 5 个按钮（返回 + 4 个分类），各 44×44px，触控区域从容舒适。

---

### 2.2 Row 2: 操作工具栏 (`MediaSearchBar`) —— 核心控制中枢
Row 2 严格按照用户指定的水平视觉流向布局：
`[卡片/列表] [⭐收藏模式]   [🔍 搜索]   [xx/xx]   [上一页] [下一页]`

#### (1) `[卡片/列表]` 视图切换键
- 尺寸：移动端 `44×44px`，桌面端 `px-[20px]`，圆角胶囊；
- 图标：`.cardViewIcon` (`\F0570`) ⇄ `.listViewIcon` (`\F0572`)。

#### (2) `[⭐ 收藏模式]` 双态切换按钮（点亮 / 点暗）
- **位置**：紧跟在视图切换键右侧。
- **触控规格**：移动端 `44×44px`（`rounded-full` 或 `rounded-lg`），桌面端带文字「收藏」；
- **状态行为**：
  - **点暗态 (Dimmed / 发现模式 - 默认)**：
    - 视觉：半透明柔白背景 `bg-[#fff3]`，白色空心星标 `.starOutlineIcon` (`\F04CF`)；
    - Tooltip / Title：`当前:全网发现,点击切换到收藏模式`；
    - 行为：下方展示对应平台的在线搜索与推荐内容。
  - **点亮态 (Lit Up / 收藏模式 - 激活)**：
    - 视觉：深色高亮半透底 `bg-[#00000080]`（或金色微光边框），明黄色高饱和实心星标 `.starSolidIcon` (`\F04CE`)，带微缩放回弹微动效；
    - Tooltip / Title：`当前:我的收藏,点击切回全网发现`；
    - 行为：下方内容**无缝切换为当前平台下的已收藏条目**。

#### (3) `[🔍 搜索]` 动态输入栏
- **正常模式（点暗）**：调用宿站输入框进行全网 API 检索，占位符为「点击搜索...」；
- **收藏模式（点亮）**：调用宿站输入框，占位符自动变为「在收藏中过滤...」，输入关键字即时触发本地 IndexedDB 模糊过滤。

#### (4) `[xx/xx]` 分页指示器
- 展示当前筛选结果的 `当前页 / 总页数`。收藏模式下根据当前收藏总数除以 10 动态计算。

#### (5) `[上一页]` 与 `[下一页]` 分页药丸
- 移动端保持 `48×44px` 放大触控药丸，上一页浅色、下一页深色半透底。

---

### 2.3 Row 3 与 Row 4: 平台与子分类联动

当 Row 2 的「⭐ 收藏模式」**点亮激活**时，Row 3 和 Row 4 保持平台不变，但子分类标签联动切换为收藏类型过滤器：

#### A. 处于「音乐」分类（Category 0）时：
- **Row 3 (平台栏)**：
  - `[网易云音乐]` · `[JOOX]` · `[无线电广播 (灰显或隐藏)]`
- **Row 4 (子分类标签联动)**：
  - 选中「网易云音乐」时：
    - 标签组变为：`[全部]` (默认) · `[单曲]` · `[专辑]` · `[歌单]`
    - 点击各标签即可无缝切换浏览网易云不同形态的收藏。
  - 选中「JOOX」时：
    - 标签组变为：`[单曲]` (或 `[全部]`)

#### B. 处于「视频」分类（Category 1）时：
- **Row 3 (平台栏)**：
  - `[哔哩哔哩视频]` · `[多源剧集检索]`
- **Row 4 (子分类标签联动)**：
  - 选中「哔哩哔哩视频」时：
    - 标签组变为：`[全部]` · `[视频]`
    - 点击即可查看收藏的 B 站视频列表。

## 3. 状态切换与生命周期重置
1. **跨大类切换（音乐 ⇄ 视频）**：
   - 收藏模式保持或根据用户偏好记忆（`favoritesModeActive: boolean`）；
2. **切入收藏模式（点亮）**：
   - 即时清空当前在线搜索流，将当前页重置为 `currentPage = 1`；
   - 触发 `FavoritesStorageService.query({ platform, type })` 加载本地数据并渲染；
3. **切回发现模式（点暗）**：
   - 恢复上一轮在线搜索的关键词与结果，体验自然连续。
