# 插件移动端交互体验与行为规范 (EXPERIENCE.md)

## Foundation

本规范界定 IIROSE-MEDIA-WEB 媒体点播插件在移动终端（安卓与 iOS 触屏手机、折叠屏外屏及窄屏窗口）下的信息架构、手势链路与行为基线。
由于插件运行在宿站 `messages.html` iframe 上下文中，实测表明宿站施加了动态视口换算（物理宽度 360~430px 时 iframe 宽度浮动于 420~486px 并在边缘越过 490px），因此**交互行为与布局策略必须由“桌面/移动两态”升级为“容器自适应能力感知”**。

---

## Open Questions 决议归档（Resolutions）

### Q1: 安卓实机上插件容器（iframe）的实际 CSS 宽度与断点失效判定
- **实测事实**：
  - 390px 设备物理视口 -> `messages.html` 实测 `window.innerWidth = 465px`
  - 412px 设备物理视口（主流安卓 Galaxy/Pixel）-> 实测 `window.innerWidth = 470px`
  - 430px 设备物理视口（大屏机型）-> 实测 `window.innerWidth = 486px`
  - 稍宽设备或横屏状态立即越过 490px 临界线，直接导致 `max-[490px]` 媒体查询失效。
- **UX 决议**：
  - **断点机制重塑**：废弃脆弱的 `max-[490px]`。将移动端紧凑布局断点统一上调为 **`max-[768px]`**（即宿站平板/手机统一使用移动端高密度模式），或直接基于插件根容器宽度判定。
  - **P0 根治原则**：第二顶栏及核心操作按钮在移动形态下**彻底移除汉字文字节点**，从 DOM/样式双重层面消灭“文字折成两行”的物理基础。

### Q2: 第三栏平台名与第四栏子分类在窄屏的形态
- **UX 决议**：
  - **第三栏平台名**：采用**紧凑相连的长方形选项卡**（gap: 0），保留品牌 Logo 与平台文字标签（`text-xs`，如“网易云音乐”、“JOOX”、“无线电广播”）。360px 宽度下横排完全可容纳 3~4 个平台标签且零溢出，既消除了圆形头像感的认知成本，又保持了桌面端与子分类栏一致的分段视觉。
  - **第四栏子分类**：保留紧凑纯文本标签（如“搜索音乐”、“搜索专辑”、“搜索MV”、“搜索歌单”），收缩 padding，开启横向弹性滚动，右边缘增加渐变淡出蒙层提示滑动。

### Q3: 顶栏信息架构与对齐
- **UX 决议**：
  - **Row 1 主导航**：音乐、视频、设置、关于四颗图标按钮保持紧密相连（gap: 0），无缝形成一体化分段控制栏。
  - **Row 2 搜索与分页**：统一靠右排布，与分页控制（页码、上一页、下一页）紧密贴合，左侧仅保留视图切换按钮（`mr-auto` 撑满中间空间）。
  - **Row 3 平台切换**：无缝长方形选项卡横排。
  - **Row 4 子分类栏**：横滑渐变标签栏。
  - 详见后文《Information Architecture》。

### Q4: 触控尺寸与防误触规范
- **UX 决议**：
  - 采用 **视觉紧凑、热区外扩** 原则：按钮视觉尺寸可为 32×32px 或 36×36px，但点击响应区域通过 padding / pseudo-element 确保达到 **≥40×40px**。
  - 分页高频动作按钮间距保持 **≥4px ~ 8px**，杜绝小屏连点误触。

### 遗留项 A5: 列表视图 375px 超窄屏下按钮挤压歌名
- **UX 决议**：
  - 列表行右侧双按钮由 128px 矩形块改为**双图标分段方钮（合计 80px，间距 0 或药丸分隔）**。
  - 歌名区域宽度直接释放近 50px，单行文本超出以省略号（`text-ellipsis`）截断。

## Information Architecture (IA)

### 移动端四层顶栏结构

```
┌────────────────────────────────────────────────────────┐
│ [←]                                       [🎵][🎬][⚙][ℹ]│  Row 1: 全局主控与导航 (40px, 紧密相连)
├────────────────────────────────────────────────────────┤
│ [⊞]                  [🔍 关键词] [📖 1/20] [ < ] [ > ] │  Row 2: 搜索与分页 (40px, 统一靠右)
├────────────────────────────────────────────────────────┤
│ [网易云音乐][JOOX][无线电广播]                         │  Row 3: 平台切换 (36px, 紧密相连)
├────────────────────────────────────────────────────────┤
│ [搜索音乐][搜索专辑][搜索歌单]                     ▒▒> │  Row 4: 子分类横滑栏 (32px, 带渐变)
└────────────────────────────────────────────────────────┘
```

1. **Row 1（主控与主导航）**：
   - 左翼：返回宿站 `BackIcon`（返回聊天主界面）。
   - 右翼：业务大类切换（音乐 / 视频 / 设置 / 关于），40×40px 无缝拼接。
2. **Row 2（操作与分页）**：
   - 左翼：视图切换方圆钮（卡片 ⊞ / 列表 ☰ 瞬时切换）。
   - 右翼：搜索胶囊与分页单元统一靠右排列，与桌面端保持一致布局逻辑。
3. **Row 3（平台切换）**：
   - 长方形无缝选项卡，轻触切换业务线平台，顶栏实时渐变至对应品牌色。
4. **Row 4（子分类标签）**：
   - 随平台动态加载子类目，支持水平手势平滑滚动。

## Interaction Primitives

1. **快速轻触与按压反馈**：
   - 触控反馈动画时长严格限制在 **80ms ~ 120ms**（`duration-100!`），使用微缩放 `active:scale-95`，避免宿站全局 `transition: all .5s` 带来的粘滞顿挫感。
2. **触屏 Hover 门控**：
   - 所有高亮态全部绑定 `@media (hover: hover)`（`hov:` 变体），移动触屏设备点击后绝不残留半透高亮层。
3. **滑动手势支持**：
   - 插件内容区支持左右轻扫翻页手势（MediaContainerGesture），手势触发阈值优化为 48px，与纵向滚动无冲突。

## Key Flows

### 核心路径：移动端小屏极速点歌

1. **呼出插件**：
   - 用户在手机双指下滑或点击快捷悬浮入口，插件由右侧平滑滑入（250ms ease-out）。
2. **选择平台与类目**：
   - 在 Row 1 直接轻触熟悉的品牌 Logo（如网易云红标、JOOX 绿标），顶栏实时渐变至对应品牌色。
   - Row 3 自动联动刷新为该平台的子分类，单手拇指即可在 Row 3 横滑点选。
3. **搜索歌曲**：
   - 点击 Row 2 中央的搜索胶囊，呼出宿站原生输入弹窗。
   - 输入歌名（如“周杰伦”）并回车，搜索栏立即更新为“周杰伦”，结果列表秒级呈现。
4. **浏览与点播**：
   - 列表视图下，每首歌左侧呈现 56px 清晰封面，右侧为明确的【耳机播放】与【加歌单】两颗独立图标按钮。
   - 拇指点击【播放】，按钮即时触发 `active:scale-90` 反馈，控制台发出 socket 媒体事件，宿站提示条弹出“点播成功”。

## Accessibility & Guardrails

1. **命中区兜底**：所有顶栏图标按钮外层包裹 `min-w-[40px] min-h-[40px]` 的透明响应区。
2. **视觉无折行断言**：在 320px ~ 480px 任何移动设备尺寸下，顶栏全部行高保持固定像素，不产生纵向抖动。
3. **极端窄屏防御**：在 360px 宽度下，搜索关键词自动缩减最大宽度（`max-w-[70px]`）并出省略号，优先保全分页与视图切换控件。
