# 下线网易云音乐和哔哩哔哩视频的开发者 API 节点

## Description

在两个平台的「默认API」中移除「开发者模式」，并在升级时把使用该节点的用户自动迁移到广州。

## Requirements

1. **设置选项**
   **Given** 用户使用正式版或开发版插件\
   **When** 用户打开任一平台的「默认API」\
   **Then** 选择框只显示原有的广州和香港节点。
2. **旧设置迁移**
   **Given** 用户曾为任一平台选择「开发者模式」\
   **When** 更新后的插件首次启动\
   **Then** 该平台自动保存广州为默认 API 节点\
   **And** 打开设置前发出的平台请求也从广州发起。
3. **后续选择**
   **Given** 用户已选择香港，或迁移后手动改选香港\
   **When** 用户再次启动插件\
   **Then** 该平台继续使用香港。

## Boundaries

- 迁移只处理两个平台的旧默认 API 选择，各平台的其他偏好独立保留。

## Notes

- 风险低，迁移范围限于两个平台各自保存的 API 节点选择。
