# 在点歌台底部条一键关闭媒体

## Description

用户想在点歌台里直接关掉本机的媒体，不必再去宿站侧栏找「其他 → 关闭媒体」。房间里正放别人的歌时，左滑面板点音符就能关，还算顺手；但自己点的歌放完、房间没歌了，媒体仍开着，要关只能走侧栏「其他 → 关闭媒体」，路径深。本票在底部条（桌面）和展开的底部条（手机）加一个「关闭媒体」钮，效果与宿站「其他 → 关闭媒体」完全相同。

## Requirements

Verify: 真站视频分享房，桌面 1280×720 与手机 400×800、宿站浅色与深色各走一遍：自己点一首歌放完后，打开点歌台点「关闭媒体」，本机媒体关闭，结果与侧栏「其他 → 关闭媒体」一致，聊天区不出现任何消息。

1. **与宿站「关闭媒体」同效**
   **Given** 宿站本机媒体处于打开状态（正在播放，或播完后仍开着、底部条显示「房间暂时安静」）
   **When** 用户点底部条上的「关闭媒体」
   **Then** 本机媒体关闭，表现与在侧栏点「其他 → 关闭媒体」相同
   **And** 不发任何聊天消息、不发 `cut`
   **And** 关闭后底部条跟着本机媒体状态走：即使房间里别人的歌还在放，本机显示「房间暂时安静」也属预期

2. **只在有媒体可关时可用**
   **Given** 宿站本机媒体已经关闭（刚进房还没媒体，或已经关过）
   **When** 用户查看底部条
   **Then** 「关闭媒体」钮不可点（灰化并带提示「当前没有打开的媒体」），点击无任何效果
   **And** 媒体再次打开（有人点播起播）后，钮在 1 秒内恢复可点

3. **桌面与手机都能一步够到**
   **Given** 点歌台已打开，宿站本机媒体打开
   **When** 桌面看底部条右栏、手机展开迷你条
   **Then** 桌面在右栏两个模式开关旁看到「关闭媒体」钮；手机在展开的底部条第一行右上角、收起箭头左边看到它，点击区不小于 44px
   **And** 底部条宽度 <816px（右栏收到 210px）时，两个模式开关只显示图标、不显示文字，三个钮都完整可见不被裁切；≥816px 时模式开关仍是图标 + 文字
   **And** 钮有可读名称（悬停提示与无障碍名都是「关闭媒体」），键盘 Tab 能聚焦、Enter / 空格能触发

4. **关闭失败不静默**
   **Given** 宿站的关闭媒体入口不存在或调用抛错（宿站改版）
   **When** 用户点「关闭媒体」
   **Then** 出现一次失败提示，插件其余功能照常
   **And** 不退回到发 `cut` 或其他会影响全房的做法

## Boundaries

- Must not change: 单曲循环与收藏随机的行为——用户手动关闭媒体不能被当成「自己喊 cut」或播放结束而触发自动重播 / 自动续播；若关闭时某个模式点亮着，关闭后它按「暂无播放内容」的现有规则熄灭。
- Must not change: 底部条现有三栏布局与窄屏收窄（左右栏 280 / 260px，<816px 收到 190 / 210px），中栏进度轨宽度不因新钮被挤掉；窄屏下模式开关改为纯图标是本票唯一允许的变化，开关的悬停提示与无障碍名仍写全称。
- Must not change: 宿站侧栏「其他 → 关闭媒体」和左滑面板音符的原有行为。
