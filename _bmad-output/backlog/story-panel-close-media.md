# 在点歌台底部条开关本机媒体加载

## Description

用户想在点歌台里直接开关本机的媒体加载，不必再去宿站侧栏找「其他 → 媒体加载」。房间正放别人的歌时，左滑面板点音符就能关；但自己点的歌放完、房间没歌后，左滑面板里没有入口了，只能进侧栏「其他 → 媒体加载」关闭。经真站确认，宿站侧栏与左滑音符操作的是同一个本机「媒体加载」双态开关（关闭后下一首歌不会自动恢复，需再次开启）。本票在点歌台底部条（桌面右栏、手机展开层）加入同步的媒体加载双态开关，并放开手机空闲态展开底部条，让歌放完后也能直接操作。

## Requirements

Verify: 真站视频分享房与非媒体房间（如大厅），桌面 1280×720（及底部条宽度 <816px 窄窗口）与手机 400×800、宿站浅色与深色各走一遍：播放中与歌放完空闲后，点击点歌台底部条的媒体开关能关闭并重新开启本机媒体加载，宿站侧栏「其他 → 媒体加载」与左滑面板音符同步变化，聊天区与网络均无 `cut` 或公聊消息发出；非媒体房间按钮灰化且点击提示不支持；睡眠模式下点击弹出宿站退出睡眠确认框。

1. **与宿站本机「媒体加载」双态开关同效且实时同步**
   **Given** 处于支持媒体的房间且未开启睡眠模式（无论房间正在播放，还是歌已放完、底部条显示「房间暂时安静」）
   **When** 用户点击底部条上的媒体开关
   **Then** 本机媒体加载在「已开启」与「已关闭」间切换：关闭时立即停止本机音视频播放并阻止后续曲目出声，再点一次恢复播放；效果与宿站侧栏「其他 → 媒体加载」及左滑面板音符完全一致
   **And** 零聊天消息、不发 `cut`、不发出任何 WebSocket 报文
   **And** 双向同步：在点歌台切换后宿站侧栏与左滑音符立即更新；在宿站侧栏、左滑音符或快捷键切换后，点歌台按钮状态在 1 秒内同步
   **And** 关闭媒体加载后，底部条仍按房间实际播放状态显示（房间在播别人的歌时照常显示曲目与进度，不会误显示「房间暂时安静」）

2. **非媒体房间灰化并提示原因**
   **Given** 处于不支持媒体的房间（如大厅）
   **When** 用户查看或点击底部条上的媒体开关
   **Then** 按钮呈灰化不可用态，保留可聚焦（沿用相邻模式开关的 `aria-disabled` 规则）；悬停提示与点击提示均为「当前房间不支持媒体加载」，点击不触发任何宿站切换动作
   **And** 进入支持媒体的房间后自动恢复可用

3. **睡眠模式下走宿站原生确认流**
   **Given** 处于支持媒体的房间且宿站已开启「睡眠模式」
   **When** 用户点击底部条上的媒体开关
   **Then** 按钮点击前显示为已关闭状态；点击后弹出宿站原生的关闭睡眠模式确认框（与左滑面板音符一致）
   **And** 用户确认后退出睡眠模式并开启媒体加载，取消则维持睡眠模式与媒体关闭状态

4. **桌面、窄窗与手机（含空闲态）都可操作且两态可辨**
   **Given** 点歌台已打开
   **When** 桌面查看底部条右栏，或手机点击迷你条主体展开底部条（无论房间在播还是空闲显示「房间暂时安静」）
   **Then** 桌面在右栏两个模式开关旁看到纯图标媒体开关；底部条宽度 <816px（右栏收到 210px）时，两个模式开关只显示图标不显示文字，三个按钮完整可见不被裁切；≥816px 时模式开关保持图标 + 文字
   **And** 手机在房间空闲时也能点击迷你条主体展开底部条（且歌曲播完停播时不再强行收起已展开的底部条）；展开层第一行右上角、收起箭头左边显示媒体开关，点击区不小于 44px；空闲态展开层不画进度轨、不显示「Now in room」标签
   **And** 开启态与关闭态在图标与中性墨色层级上可一眼区分（不占用蔷薇红强调色），悬停提示与无障碍名称随当前动作切换（「关闭媒体」/「开启媒体」，非媒体房 `aria-label` 附带不支持原因），支持键盘 Tab 聚焦与 Enter / 空格触发

5. **宿站入口缺失或调用抛错时不静默**
   **Given** 处于支持媒体的房间，但当前路径所需的宿站入口缺失或调用抛错（例如常规态缺少媒体开关函数、睡眠态缺少退出睡眠确认函数）
   **When** 用户点击底部条上的媒体开关
   **Then** 出现一次失败提示，插件其余功能照常
   **And** 不绕过睡眠确认直接强切，也不退回到发 `cut` 或其他会影响全房的做法

## Boundaries

- Must not change: 单曲循环与收藏随机保持独立——关闭或重新开启本机媒体加载不能被当成 `cut` 或播放结束；若操作时单曲循环或收藏随机正点亮，保持点亮不自动熄灭，继续由各自的模式开关控制。
- Must not change: 桌面底部条三栏布局与窄屏收窄尺寸（左右栏 280 / 260px，<816px 收到 190 / 210px），中栏进度轨宽度不因新钮被挤掉；窄屏下模式开关改为纯图标是本票唯一允许的变化，开关的悬停提示与无障碍名仍写全称。
- Must not change: 手机迷你条本身不新增按钮，展开层的收起方式（收起箭头、点外侧遮罩、切模式、关面板、Esc / 宿站返回键）及焦点归还规则保持不变。
- Must not change: 宿站侧栏「其他 → 媒体加载」、左滑面板音符及快捷键 `Ctrl+M` 的原有行为。
