# 视觉语言（visual-language）

主面板与两个浮窗共用的视觉规范；令牌与控件常量的唯一来源是 `src/page/components/floating-panel/`。

## 令牌

| 令牌 | 浅色 | 深色 |
| --- | --- | --- |
| 浮窗表面 | `#fafbfe` | `#242a34` |
| 主面板底色 | `#eef1f6`（柔灰） | `#242a34` |
| 主面板卡片 | `#fff` + black/8 描边 + 轻阴影 | 深色次级表面 + white/10 描边 |
| 正文 | `#253047` | `#f4f6fa` |
| 描边 / 分隔 | `black/10` | `white/15` |
| 次要文字 | `opacity-65` | `opacity-65` |
| 强调 | 浮窗 `sky-500`；主面板为当前平台品牌色（过浅时压深） | `sky-500`（不融入品牌色） |
| 顶部光晕 | 顶部四行背后品牌色约 16% 渐隐 | 无 |
| 悬停 / 按压 | 浮窗 `sky-500/8`/`/15`；主面板 `--imw-accent` 的 /8、/15 | 主面板同浮窗（天蓝） |
| 次级表面（卡片内区、选中行、紧凑按钮组） | 主面板 `--imw-accent`/10；浮窗 `sky-500/8` | `white/[0.04]`，强调叠 `sky-500/10` |

- 圆角：大容器 `rounded-2xl`，卡片 `rounded-xl`，按钮/输入/标签 `rounded-lg`。
- 阴影：浮窗外框保留 `0 12px 40px rgba(0,0,0,.25)`；主面板内部卡片不用大阴影，靠描边分层。
- 字号：标题 15px semibold，正文 14px，次要 12px，标签 12–13px。

## 控件

| 控件 | 规范 |
| --- | --- |
| 主按钮 | 天蓝实底白字，`rounded-lg`，禁用 `opacity-40` |
| 次要按钮 | 透明底 + 主题描边，`rounded-lg`，悬停淡天蓝 |
| 图标按钮 | 44×44，透明底，悬停淡天蓝 |
| 搜索框 | 描边 `rounded-lg`、左侧放大镜，聚焦描边天蓝 |
| 分段标签 | 相连长方形，选中段天蓝实底白字，其余透明底；首尾圆角 |
| 卡片 | 表面色 + 主题描边 `rounded-xl`，封面圆角随卡片 |
| 加载 / 空状态 | 天蓝转圈；空状态图标天蓝、文字次要色 |

## 主面板布局保持

Row1–Row4 尺寸、触控与排布按 AGENTS.md「顶栏布局与触控目标约定」，本规范只替换颜色、描边、圆角与控件样式。

## 强调色可读性

- 浅色主面板的 `--imw-accent` 由平台品牌色经 `readableAccent` 压深得到：白字在强调色填充上、强调色文字在最深的实际背景（`#eef1f6` 叠约 26% 强调色）上都 ≥4.5:1。
- 已知限制：深色主题强调色为 `sky-500`，白字在其实心填充上约 2.8:1（与浮窗主按钮一致），本轮不改。
