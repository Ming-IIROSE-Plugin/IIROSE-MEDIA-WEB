# 点歌台 Media Desk — Experience Spine

## Foundation

- **产品定位**：房间点歌台。核心任务是**几秒内找到并把歌/视频点播到房间**；次要任务：看房间正在放什么、收藏与随机、设置。
- **形态**：嵌入 iirose.com `messages.html` iframe 的**全幅叠加面板**（主面板 `.IIROSE_MEDIA_CONTAINER`）。两种形态：桌面与手机，断点 768px（`max-[768px]`）。浅色/深色**跟随宿站主题**（宿站 `window.theme`，与浮窗同一判定），无独立主题开关。
- **技术**：不用 UI 组件库——Preact + Tailwind v4（任意值类，深色用 `imw-dark:` 变体）。图标自包含（内联 SVG）。
- **视觉参考**：`DESIGN.md` 是视觉规范；本文件是行为规范。
- **界面语言**：仅中文。
- **工作模式**：快速路径——本规格直接用于拆 story。定稿前运行规格完整性检查（rubric walker）。
- **范围内的改版 story**：主面板（含设置页、关于页换新令牌）；选集面板（替代宿站 `buildSelect2`）；浮窗改版（播放进度浮窗与收藏随机选择面板换新配色）；最近点播历史（**新代码**：现有 `src/` 只有 `MediaPayloadMemory` 的单条报文缓存，没有点播历史存储）；AGENTS.md 约定重写（见下）。
- **作废并重写的约定**：AGENTS.md 中现行「顶栏布局与触控目标约定」（Row 1–4）与「主面板颜色一律取 floating-panel 的 `themed*` 令牌」**由本规格取代**，改为 DESIGN.md 的新令牌与本文件的新布局约定；保留 44px 触控与 `max-[768px]` 断点约定。由一个独立 story 改写 AGENTS.md，**必须与第一个主面板 story 同轮完成**——在改写之前 AGENTS.md 仍要求 `themed*`，dev agent 会照它执行而与 DESIGN.md 冲突。

## Component Patterns

行为规则；视觉见 DESIGN.md Components（括号内为组件键，名称见 Foundation「术语」）。

| 组件 | 用途 | 行为规则 |
| --- | --- | --- |
| 竖栏 / 底部标签栏（`rail` / `bottom-tab-bar`） | 切换模式 | 单击即切换；选中态见 `components.rail-item-active` / `components.bottom-tab-bar`（item-active）。切换模式时搜索栏的来源、作用与范围随模式变化。 |
| 品牌标（`brand-mark`） | 竖栏顶部 | 无操作、不可聚焦。 |
| 搜索栏（`search-bar`） | 主入口 | 桌面打开面板时光标已在搜索栏（J1）；**手机不自动聚焦**。Enter 或「搜索」按钮提交。键位提示（桌面）：未聚焦且为空显示 `/`；**已聚焦且为空不显示**（已经在输入，「按 / 聚焦」多余）；有内容显示 `Enter`。与「搜索」按钮之间留 10px。 |
| 粘贴识别 | 搜索栏 | 粘贴 BV 号或链接时自动识别并提交；在音乐模式粘贴视频链接，自动切到视频模式再提交。 |
| 来源切换器（`source-switcher`）/ 来源菜单（`source-menu`） | 搜索栏左端 | 点击（或聚焦时按 ↑/↓）展开插件自有下拉菜单（不用原生 select）；只有一个来源时仍显示。收藏模式下为「全部 / 网易云 / B站」筛选器。菜单：↑/↓ 移动、Home/End 到首尾、Enter/空格选中、Tab 离开即收起；点菜单外收起不切换；选当前项不重复触发；`Esc` 与宿站返回键只关菜单（面板层级 `source`，与操作条、展开的底部条、顺序菜单互斥）；收起后焦点回到切换器。打开时箭头翻转。 |
| 收藏过滤 | 收藏模式搜索栏 | 输入即过滤本地收藏，匹配标题/歌手/作者，不发请求、不区分大小写；与来源筛选叠加。 |
| 电台过滤 | 电台模式搜索栏 | 输入即过滤当前地区的电台名。 |
| 范围标签（`scope-tab`） | 搜索栏下 | 单选；切换即重新请求当前关键词在该范围的结果（收藏、电台为本地切换），页码回到 1、结果区滚到顶部。选中项可附结果总数（`单曲 300`）。电台模式为地区标签。下划线整行一条，切换时滑到新标签（首次定位不滑）。 |
| 视图切换（`view-segmented`） | 范围行右侧（桌面与手机），**常驻不消失** | 列表 / 网格。音乐单曲（含首屏「最近点播」）、视频（含多源）、收藏可切换；收藏网格为方形卡混排（视频封面方形裁切）。专辑/歌单、电台只有列表，MV 只有网格：切换仍在原位，灰色锁定（非当前项 40% 不透明），悬停提示「这里只有列表视图 / 网格视图」。专辑/歌单内页由内页头接管，不显示范围行。〔2026-10-30 维护者决策：取代旧的「不显示视图切换」假设〕 |
| 分页（`pager-button`） | 范围行右侧（桌面与手机） | 上一页/下一页 + 等宽页码 `01 / 28`。不做无限滚动。翻页后结果区滚到顶部。 |
| 点播守卫 | 所有手动点播入口（曲目行、网格卡、视频卡、操作条、收藏、最近点播、电台、「全部播放」、收藏里专辑/歌单选完正序/乱序） | **同一条目点播进行中再点无效**（防连点刷屏），按钮原地「点播中」转圈，直到**第一条点播报文真正发出**即恢复可点——**没有冷却、没有「已点播」态**，发出后可以立刻再点。成功判据是发出的 `&1` 媒体报文；平台层弹出失败提示（含被 10 秒去重吞掉的同因失败）→ 按钮「重试」并轻晃，3 秒后恢复；既没报文也没提示（弹出了选集面板或正序/乱序菜单）→ 安静回到常态，不算失败。电台流几乎瞬间发出，「点播中」至少停留 1 秒。整张歌单在第一首发出时即解锁，其余在后台继续（进度见批量点播进度卡）。不同条目互不影响。 |
| 曲目行（`tracklist-row`，桌面） | 音乐、收藏、电台、专辑/歌单内页 | 点「点播」把该条送到房间（公聊点播卡片 + 媒体报文，沿用现有播报档位），并写入最近点播；状态见点播守卫。悬停整行高亮、按钮转实心——**仅在 `hov:` 门控下**。房间正在放的曲目显示音柱与蔷薇红标题，仍可再次点播。 |
| 曲目行（`tracklist-row-phone`，手机） | 同上 | 40px 点播按钮一键点播；点行的其他区域弹出操作条。 |
| 音乐网格卡（`music-tile`） | 音乐单曲（含首屏）、收藏、专辑/歌单内页的网格视图 | 与曲目行同一组操作：桌面悬停（或无悬停设备点按选中、键盘聚焦）出现「点播」胶囊，点即点播；点播中 / 失败期间胶囊保持可见；收藏星在卡内；手机点卡片弹出操作条（点播到房间 / 收藏），**手机上胶囊不常显**。收藏网格里的专辑/歌单卡：胶囊为「查看」，点卡片或胶囊进内页（手机点卡片直接进内页），不点播。 |
| 专辑/歌单行（`collection-row`） | 音乐 · 专辑、歌单范围；收藏里的专辑与歌单 | **桌面整行不可点**（整行可点会让收藏星很难点中——用户反馈）：只有封面、标题（悬停下划线）与行尾「≡ 查看」三处进入；收藏星独立可点。**手机整行点按进入**（手机无星标列）。进入后**在面板内打开其曲目列表**：范围行替换为专辑/歌单内页头（`collection-header`，含视图切换与分页），列表为该专辑/歌单的曲目行（可切网格），按曲目行规则点播；「‹ 返回」、`Esc`、宿站返回键回到原结果列表，保留原关键词、页码与滚动位置。行本身不提供整张点播；整张点播在内页头「全部播放」：点后弹出顺序菜单（`order-menu`，桌面小浮层、手机操作条）「正序播放 / 乱序播放」，选定即按该顺序点播整张列表（批量播报，沿用现有整单点播），点外侧、`Esc`、宿站返回键 = 取消不点播。房间不支持点播时「全部播放」灰化。「全部播放」只在按钮自身悬停时转实心，菜单打开期间按钮淡底。选定顺序后：该条目进入点播守卫（第一首发出前为「点播中」），并出现批量点播进度卡。 |
| 视频卡（`video-tile`） | 视频结果、音乐 · MV 范围 | 桌面有悬停时：悬停出现「点播到房间」，点即点播。**无悬停的宽屏设备**（> 768px 且 `@media (hover: none)`，如 iPad 横屏）：第一次点按卡片只选中并显示「点播到房间」（`video-tile-revealed`），再点该按钮才点播；点另一张卡改选它，点空白处取消选中。**键盘**：卡片内获得焦点（`:focus-within`）时同样显示「点播到房间」，Tab 先到缩略图链接区、再到「点播到房间」。多 P / 多集条目点播时先开选集面板。MV 与普通视频完全同一行为。 |
| 直播卡（`video-tile` + `live-badge`） | 视频 · 直播范围 | 同视频卡；右下角显示「直播」徽章、不显示时长。点播后底部条进入直播态（见 State Patterns）。 |
| 收藏星（`favorite-star`，桌面） | 曲目行、专辑/歌单行、音乐网格卡 | 单击切换收藏，即时生效；只在用户亲手点亮时弹跳一下（加载出来就已收藏的星不弹）。 |
| 操作条（`action-sheet`，手机） | 手机曲目行、视频缩略图、音乐网格卡 | 手机没有悬停：点曲目行（点播按钮以外的区域）或缩略图，从底部升起操作条，含「点播到房间」「收藏」「选集」（单 P 条目不显示「选集」）。点选项即执行并收起；点操作条外、宿站返回键、`Esc` 收起。**挂在主面板内部、作为面板内最上层**：只随主面板出现，主面板关闭时一并关闭，不另设 z-index 根。与展开的底部条互斥（打开一个先收起另一个）。 |
| 选集面板（`episode-picker`） | 多 P 视频 / 多集剧集 | 插件自有浮层，**替代宿站 `buildSelect2`**（不再受宿站弹窗淡出冲突约束）。多选；按点选顺序显示序号徽章 1、2、3…，取消某项后其后序号前移；「全选」按列表顺序选中全部（徽章 1…N），全部选中时变「取消全选」，点即清空；「正序 / 乱序」默认**正序**；未选任何项时「点播所选」禁用。确认后按所选顺序（或乱序）点播，业务层按此顺序重排接口返回结果；选了多项时出现批量点播进度卡。歌单的条目以 `trackIds` 为完整列表与顺序（部分网络下详情接口的 `tracks` 只给前 10 首），缺的曲目按 id 分批（每批 100）补取详情，取不到的仍列为「曲目 N」并可选——上千首的歌单也全部列出，在面板内滚动，不分页。关闭钮、点面板外、`Esc`、宿站返回键 = 取消，不点播。桌面为浮层卡片，手机为底部抽屉；层级同收藏随机选择面板。 |
| 底部条（`room-deck`）/ 迷你条（`mini-deck`） | 面板底部常驻 | 显示房间当前媒体（不论谁点的）、点播者、进度。面板打开时由它承担进度与模式开关。桌面底部条主体（封面与标题区）点击无操作。**桌面在设置、关于两页不显示**（不是点歌页面，把高度还给内容；切回其他模式即恢复，播放状态不受影响）；手机迷你条各页都在。进度拖柄平时隐藏，悬停 / 键盘聚焦 / 按下时出现（手机展开态常显）。 |
| 展开的底部条（`room-deck-expanded`，手机） | 点迷你条主体（封面与标题区，模式钮以外） | 迷你条展开为完整底部条：可拖动进度轨（权限规则同下）、两个带文字的胶囊模式开关（`mode-toggle-sheet`）。展开从底部升起；收起（点收起钮、点展开区外、`Esc`、宿站返回键、切换模式、打开操作条）时先向下滑出再卸载；面板整体关闭时直接卸载；系统「减少动态效果」时改为淡入淡出。焦点移入收起钮、收起后还给迷你条主体，移动焦点不滚动面板（否则动画起点会让面板跳动）。房间无播放时点迷你条主体不展开。层级与操作条同级。 |
| 进度跳转 | 桌面底部条进度轨；手机展开的底部条进度轨（迷你条顶边进度线只显示） | 可拖动或点击跳转，权限与播放进度浮窗一致：**有媒体权限或本人点播可调，否则只显示**；复用现有跳转逻辑。不可调时不显示拖柄、不响应点击与拖动。直播/电台流一律不可跳转。 |
| 模式开关（`mode-toggle`） | 底部条/迷你条/展开的底部条 | 「单曲循环」「收藏随机」互斥（点亮其一熄灭另一，再点熄灭）。「收藏随机」熄灭态点击**只弹出收藏随机选择面板**，确认后才点亮；点亮态点击直接熄灭。待命规则见 State Patterns。规则沿用 spec-playback-loop-shuffle。 |
| 关闭按钮（`close-button`） | 页头右侧 | 关闭面板（连同面板内的操作条、展开的底部条）；播放与模式不受影响。 |
| 设置行（`settings-row`） | 设置页 | 保留现有全部设置项与动作，只换外观。**取值类**（画质、默认 API、歌词、默认页面、搜索结果视图、收藏每页显示、点播播报、播放时长等）：行末显示当前值 + chev，点整行调用现有设置动作（沿用现有宿站选择弹窗/输入框），确认后当前值即时刷新、即时生效，无「保存」按钮。**开关类**：见设置开关。**动作类**（立即同步、清空云端、忘记本机密钥）：点整行执行现有动作（含现有确认步骤），值位显示现有状态文字。**只读类**（上次同步时间、同步状态）：不可点，不显示 chev，随现有订阅实时刷新。不可用时（如「需先解锁」）值位显示现有原因文字，行可点并由现有逻辑提示原因。 |
| 设置开关（`settings-switch`） | 设置页二值项（代理蔷薇@输入、云端同步启用） | 点整行或开关切换；开态蔷薇红实底。状态以现有设置逻辑的结果为准：需要额外步骤的（云端同步启用走现有口令/确认流程）在流程完成后才显示为开，取消则保持关。替代现有 `mdi-toggle-switch` 图标式开关。`role="switch"` + `aria-checked`。 |
| 关于卡（`about-card`） | 关于页 | 沿用现有四项及其动作：作者（关闭面板后显示作者信息）、项目源代码地址（新窗口打开 GitHub）、投喂我、赞助列表。外链用外链图标，不用 emoji。 |
| 提示（`notice`） | 全局 | 失败与说明走宿站提示层 `ShowMessage.show`（`window._alert`）：加载失败、房间不支持点播、待命原因、换房、设置输入越界。同一原因在 10 秒内只提示一次（与 `neteaseRequest` 批量失败去重同一窗口）〔去重窗口推广到所有提示〕。 |
| 面板提示条（`desk-toast`） | 主面板结果区底边 | 点播成功（第一条报文发出）时显示「已点播《…》」，约 2 秒淡出；新提示直接替换旧的；`role="status"` 读屏播报。宿站提示层在面板打开时容易被遮住，成功确认放在面板里。 |
| 收藏每页显示（设置「插件设置」组） | 设置页取值行 | 宿站选择框选 10 / 50 / 100 / 自定义…；「自定义」等选择框淡出（300ms）后弹数字输入框，只接受 1–500 的整数，越界提示且不改设置。收藏页分页、外部变更触发的重载与行号都按此条数。默认 10。 |
| 批量点播进度卡（`batch-progress`） | 页面右下角（挂在 body 上） | 整张「正序/乱序播放」与选集多选确认时出现，一次批量一张卡，多张纵向堆叠。准备中（取歌单/详情）为不确定进度；之后逐首上报「已发 / 总数」（无版权跳过也计入）。**点播面板关闭后仍在、仍可操作**。「停止」：发送循环在下一首前（含取歌词之后、发送之前）看到标记即结束，已发出的不撤回；界面立即显示「已停止」，**1.2 秒后淡出**。正常播完显示「已点播完」，**4 秒后淡出**；结束后可点 × 立即关掉。 |

## State Patterns

| 状态 | 位置 | 处理 |
| --- | --- | --- |
| 音乐首屏（未搜索） | 音乐结果区 | 列出**最近点播**（曲目表样式，标题「最近点播」）：数据来自新增的本地点播历史（见下行）。无记录时显示「还没有点播记录。搜索歌名或歌手，点播到房间。」 |
| 最近点播历史 | localStorage（本机、不分房间、不进云同步） | **新代码**：插件每次成功发出点播（曲目行、音乐网格卡、操作条、收藏点播、电台、视频、选集）时写入一条，同一媒体再次点播移到最前；最多 50 条，超出丢弃最旧。首屏只列音乐来源的条目。从首屏点播时不重复计数。键名由实现定（建议 `imwRequestHistory`）。 |
| 视频首屏 | 视频结果区 | 默认范围「推荐」，有内容可看。 |
| 加载中 | 结果区 | 骨架：曲目表用 `{components.skeleton-row}`，视频与音乐网格用 `{components.skeleton-tile}`；范围行与搜索栏保持可用。 |
| 搜索无结果 | 结果区 | `{components.state-message}` 一行文案，无插画。 |
| 收藏 / 电台过滤无结果 | 结果区 | 「没有匹配的收藏」+「清除搜索」（`text-button`；电台同理）。 |
| 收藏为空 | 收藏模式 | 居中引导文案。 |
| 在收藏模式取消收藏 | 收藏列表 | 该行保留（星标变空心），离开收藏模式、切换范围/来源或改过滤词后才移除，防止误触后列表跳动、可立即再点星恢复。 |
| 加载/请求失败 | 结果区 | 「加载失败」+「重试」；网易云请求重试过程静默，全部节点失败才提示一次（既有 `SendFetch.neteaseRequest` 约定）；批量失败同因 10 秒去重。 |
| 离线 / 代理失败 | 结果区 + 提示 | 出网请求走阿里云 CORS 代理；代理不可达按「加载失败」处理，提示一次，不刷屏。风控码与超时分别归因（既有）。 |
| 封面加载失败 | 封面/缩略图/台标 | `{colors.thumb}` 底 + 自包含图标回退；`http://` 封面先升级为 `https://`（既有）。 |
| 专辑/歌单内页加载 | 结果区 | 同加载中/失败；失败「重试」只重载内页，「‹ 返回」始终可用。 |
| 重新打开面板 | 主面板 | 恢复上次关闭时的模式、关键词、范围、页码与结果（同一页面会话内，沿用现有面板状态保持）；滚动回到顶部。首次打开进入现有设置「插件启动默认页面」指定的模式。 |
| 切换模式 | 主面板 | 各模式各自保留关键词、范围与页码；关闭操作条与展开的底部条。 |
| 切换范围 / 来源 | 结果区 | 页码回到 1，滚到顶部，按当前关键词重新请求。 |
| 结果区内容切换 | 结果区 | 换页、换范围、换视图、新结果到达时，内容整体从下方 8px 淡入（200ms）；减少动态效果时直接出现。 |
| 宿站主题变化 | 主面板 | 面板每次打开时读取主题并写 `data-imw-theme`；打开期间宿站切换主题，下次打开生效（不新增监听）。 |
| 房间无播放 | 底部条/迷你条 | 显示「房间暂时安静」，**保留模式开关**；开关可用性按既有规则。 |
| 直播 / 电台流（无总时长） | 底部条/迷你条/展开的底部条 | 不显示进度轨、拖柄与总时长，改为「直播」徽章 + 等宽已播时长（`room-deck-live`）；迷你条不画顶边进度线、副行不显示时间；**不可跳转**，进度轨区域不可聚焦。播放进度浮窗同规则。 |
| 他人点播的媒体 | 底部条 | 照常显示封面、标题与「某某 点播」。进度只显示（无媒体权限时）。已点亮的模式开关保持点亮**待命**、不自动动作、不主动弹提示；首次点按只说明原因，再点才熄灭（既有规则）。 |
| 本人点播的媒体 | 底部条 | 点播者显示「由你点播」；进度可跳转。 |
| 点播进行中 | 被点的那个按钮 / 胶囊 | 「点播中」转圈、不可再点，直到第一条报文发出；电台至少 1 秒。同一条目在其他入口（如操作条）点播时同样被锁。 |
| 点播失败 | 同上 | 「重试」+ 轻晃，3 秒后恢复；失败原因由宿站提示层说明。 |
| 点播交给下一步 | 同上 | 弹出选集面板或正序/乱序菜单：按钮直接回到常态，不显示点播中（选定顺序后才进入点播中）。 |
| 批量点播进行中 / 已停止 / 已完成 | 批量点播进度卡 | 见 Component Patterns；面板关闭不影响；停止后 1.2 秒、完成后 4 秒淡出。 |
| 设置 / 关于页 | 桌面底部条 | 不显示；手机迷你条照常。 |
| 收藏里进入专辑/歌单 | 收藏结果区 | 同专辑/歌单内页；「‹ 返回」回到收藏列表（保留来源、范围、页码）。 |
| 房间不支持点播 | 所有点播入口 | `mediaShareRoom` 为 false 时，点播按钮、「点播到房间」、操作条首项、选集「点播所选」灰化；点击提示「这个房间不支持点播」。 |
| 换房 / 断线 | 模式开关 | 熄灭并提示一次原因（既有）。 |
| 选集加载中 | 选集面板 | 面板先打开，列表区为骨架行，底栏禁用。 |
| 选集为空（0 集） | 选集面板 | 「没有可点播的分集」，底栏禁用，只能关闭。 |
| 选集未选任何项 | 选集面板 | 「点播所选」禁用（40% 不透明）；「正序 / 乱序」可切换，默认正序。 |
| 选集加载失败 | 选集面板 | 「加载失败」+「重试」，不点播。〔已确认，沿用同类文案〕 |
| 设置页 | 设置结果区 | 无加载态（设置为本地读取）；云同步分组的同步状态、上次同步时间随现有订阅实时刷新；动作执行中沿用现有提示。 |
| 关于页 | 关于结果区 | 静态，无额外状态。 |

## Interaction Primitives

**层级与关闭顺序**（`Esc` 与宿站返回键共用）：

1. 选集面板 / 收藏随机选择面板（最上层，二者不会同时打开）
2. 操作条 / 展开的底部条 / 「全部播放」顺序菜单 / 来源菜单（主面板内最上层，四者互斥）
3. 主面板

每按一次只关当前最上一层。批量点播进度卡不是层：它不拦截 `Esc` 与返回键，只能用「停止」或 × 关闭。

**键盘（桌面）**

- `Alt+S` — 打开/呼出点歌台（既有）。打开后焦点在搜索栏。
- `Enter` — 提交搜索。
- `/` — 聚焦搜索栏。
- `Esc` — 按上面的关闭顺序关最上一层；在专辑/歌单内页且无浮层时，`Esc` 先返回结果列表，再按一次关闭点歌台。
- `Tab` 顺序跟随阅读顺序：竖栏 → 页头（关闭钮）→ 搜索栏（来源切换器 → 输入区 → 搜索）→ 范围行（范围标签作为一个 tablist，方向键在标签间移动 → 视图切换 → 分页）或内页头（返回 → 视图切换 → 分页 → 全部播放）→ 结果（每行/每卡：曲目行为 收藏星 → 点播；专辑/歌单行为 封面 → 标题 → 收藏星 → 查看；视频卡与音乐网格卡为 卡片主体 → 「点播到房间」/「点播」）→ 底部条（进度轨 → 单曲循环 → 收藏随机）。
- 来源菜单：在切换器上按 ↓/↑ 展开；菜单内 ↑/↓、Home/End、Enter/空格、Tab 离开即收起。
- 浮层（选集面板、收藏随机选择面板、操作条、展开的底部条、顺序菜单、来源菜单）打开时焦点移入（操作条等在其中循环），关闭后还给触发元素。
- 进度轨可聚焦时，左右方向键每次跳 5 秒，`Shift`+方向键 30 秒（仅可调时）。

**触屏（手机）**

- 双指下滑 — 呼出点歌台（既有）。
- 点曲目行（点播按钮以外）/ 视频缩略图 / 音乐网格卡 — 弹出操作条（网格卡胶囊在手机上不常显）。
- 点专辑/歌单行任意处 — 进入内页；收藏网格里的专辑/歌单卡同理。
- 点迷你条主体 — 展开底部条（可跳转进度）。
- 宿站返回键 — 按上面的关闭顺序（与收藏随机选择面板同一机制：打开期间接管 `Utils.backward`，返回只关插件浮层，关闭后交还；插件不读写浏览历史）。
- 所有可点目标点击区 ≥ 44×44px（设计稿视觉 40px 及以下的按钮外扩点击区）。

**触屏（宽屏，无悬停）**

- `> 768px` 且 `(hover: none)`：布局同桌面；视频卡与音乐网格卡「点一下选中显示按钮、再点按钮点播」；曲目行点播按钮常显（描边胶囊），直接点即点播。

**鼠标**

- 悬停效果（行高亮、点播按钮实心、视频「点播到房间」遮罩、「全部播放」实心、进度拖柄出现）一律放在 `hov:` 变体后，触屏不触发、不残留。悬停只点亮鼠标所在的那个按钮，不因所在行 / 头部整体悬停而点亮别的按钮（「查看」悬停只淡底）。

**按下与动效**

- 小控件按下缩到 96% 再回弹；时长三档 120 / 200 / 280ms，同一缓动（见 DESIGN.md `components.motion`）。
- 颜色、透明度、阴影、缩放默认过渡 120ms；宽高与位置不过渡，布局变化即时完成。
- 进度轨：可调时点击跳转、按住拖动；拖动中不被宿站滑动手势识别。

**禁止**：无限滚动；只能靠悬停才能触达的操作（手机用操作条、无悬停宽屏用点按选中、键盘用 `:focus-within` 替代）；合成事件驱动宿站输入框；跨弹窗流转依赖宿站 `buildSelect2`（选集已改为插件自有面板）。

## Accessibility Floor

视觉对比见 DESIGN.md「对比度」——调整后所有承载信息的文字组合 ≥ 4.5:1，图形部件 ≥ 3:1。

- 纯图标按钮（手机点播钮、迷你条模式钮、展开的底部条收起钮、关闭、分页、视图切换、竖栏图标）都有 `aria-label`；模式开关 `aria-pressed`，待命原因写入 `title` 与读屏状态区（既有）。
- 范围标签 `role="tablist"`，视图切换与正序/乱序 `role="radiogroup"`（视图切换锁定时两格 `aria-disabled`，组上 `title` 说明原因）；来源切换器 `aria-haspopup="listbox"` + `aria-expanded`，菜单 `role="listbox"`、项 `role="option"` + `aria-selected`；顺序菜单 `role="menu"`；当前模式在导航上 `aria-current`；设置开关 `role="switch"`。
- 点播中的按钮 `aria-busy` + `aria-disabled`，读屏名附状态（「点播 鱼：点播中」）；面板提示条与批量点播进度卡外层 `role="status"`（polite），进度条 `role="progressbar"`（`aria-valuenow` / `aria-valuemax` 为已发 / 总数）。
- 进度轨可调时 `role="slider"`（`aria-valuenow` / `aria-valuetext` 为等宽时间）；不可调或直播时为只读进度（直播读「直播，已播 mm:ss」），不可聚焦。
- 操作条、选集面板与展开的底部条 `role="dialog"`，打开时焦点移入，关闭后还给触发元素；选集项 `role="checkbox"`，读屏读出序号（「第 2 个」）。
- 「房间正在播放」行除颜色外还有音柱图形与文字后缀，不只靠颜色区分；来源圆点总配平台文字。
- 灰化的点播入口保留可聚焦与文字说明，不只靠透明度表达。
- 所有可聚焦元素 `:focus-visible` 时显示 `{components.focus-ring}`：2px `{colors.focus-ring}` 外圈、2px 间隔；蔷薇红实底控件加 `{colors.paper}` 内环；底部条已是 sheet 底，与其他表面同一外圈。各表面对比 ≥ 3:1（DESIGN.md 对比度表）。焦点环替代既有浮窗的强调色描边，浮窗改版同步采用。
- `prefers-reduced-motion: reduce` 时去掉缩放与位移动画（按下缩放、操作条升起、底部条展开、下拉落下、结果区上浮、收藏星弹跳、失败晃动、不确定进度流动），只保留淡入淡出。
- 承载信息的文字对比已全部达标（展开的底部条 `Now in room` 标签已由 55% 提到 65%，浅色 5.32）。
- 手机端点击区 ≥ 44px；手机搜索框字号 16px，防 iOS 聚焦放大。

## Key Flows

### J1 — 有人点名要歌（小飞鱼，桌面，房间聊天中）

1. 朋友在房间说想听陈绮贞。
2. 小飞鱼按 `Alt+S`，点歌台打开，在音乐模式（首屏列出最近点播），光标在搜索栏。
3. 输入「陈绮贞」，按 `Enter`。
4. 曲目表出现（单曲范围，等宽序号与时长）。
5. 鼠标移到「鱼」那一行：整行浅底，点播按钮转实心蔷薇红。
6. 点「点播」：按钮原地转圈「点播中」，期间再点无效。
7. **高潮：报文发出，按钮恢复，结果区底边浮出「已点播《鱼》」；底部条切到「鱼」，房间里出现点播卡片。**

失败：搜索请求全部节点失败 → 结果区「加载失败」+「重试」，提示一次。取音源失败 → 按钮变「重试」并轻晃，宿站提示原因。房间不支持点播 → 点播按钮已灰化，点击提示「这个房间不支持点播」。

→ 参考：[frame-1.png](imports/mock-v1/frame-1.png)（第 4–5 步的曲目表与悬停行）。

### J2 — 深夜挂机放收藏（铭铭，手机）

1. 铭铭双指下滑打开点歌台（搜索栏不自动聚焦，键盘不弹出）。
2. 在迷你条点「收藏随机」图标钮。
3. 收藏随机选择面板（新配色）弹出，勾选歌单，点「开始随机」确认。
4. 面板关闭，「收藏随机」点亮（单曲循环熄灭）。
5. **高潮：迷你条顶边进度线开始走；铭铭关掉点歌台继续聊天，歌一首接一首。**

失败：该平台没有收藏 → 面板显示「该平台还没有收藏」，「开始随机」不可用，开关保持熄灭。确认时房间在放他人曲目 → 当场提示一次待命原因，开关保持点亮待命。

### J3 — 粘贴链接点视频（阿凉，桌面，视频模式）

1. 阿凉在视频模式，往搜索栏粘贴 BV 号。
2. 插件识别出 BV 号并自动提交，结果出现。
3. 点「点播到房间」：该视频是多 P，选集面板打开（默认正序，未选时「点播所选」禁用）。
4. 点第 3 集（徽章显示 1），点「点播所选」。
5. **高潮：房间开始放这一 P，底部条显示视频封面与进度。**

分支：想点全部分 P → 在选集面板点「全选」（徽章 1…N），选「正序」或「乱序」，点「点播所选」；右下角出现批量点播进度卡，阿凉关掉点歌台继续聊天，进度卡还在，点错了随时「停止」。在音乐模式粘贴了视频链接 → 自动切到视频模式再提交。BV 号无效 → 结果区无结果文案。选集加载失败 → 面板内「加载失败」+「重试」，不点播。

→ 参考：[frame-2.png](imports/mock-v1/frame-2.png)（视频网格与悬停「点播到房间」）。

### J4 — 看看正在放什么、换循环（小飞鱼，桌面与手机）

1. 小飞鱼打开点歌台，只想知道这首是谁点的。
2. 底部条直接显示「歌手 · 某某 点播」，无需切页（手机迷你条为「某某 点播 · 01:38」）。
3. 点「单曲循环」，开关点亮（手机为迷你条上的纯图标钮）。
4. **高潮：下一轮自动重播，无需再找歌。**

分支：这首是别人点的 → 开关点亮但进入待命，当场提示一次原因，不打断对方（既有规则）；进度只显示，不能拖动。手机想跳转进度 → 点迷你条主体展开底部条，在进度轨上拖动（有权限时）。

### J5 — 手机上点一首歌（铭铭，手机，房间聊天中）

1. 铭铭双指下滑打开点歌台，点搜索栏输入「鱼」，提交。
2. 曲目行列表出现（四列：封面、标题+歌手、时长、点播钮）。
3. 一键路径：点「鱼」行右侧 40px 点播钮。
4. 或操作条路径：点「鱼」行的其他区域，操作条升起，点「点播到房间」，操作条收起。
5. **高潮：结果区底边浮出「已点播《鱼》」；迷你条切到「鱼」、显示「由你点播」，房间里出现点播卡片。**

失败：房间不支持点播 → 点播钮与操作条首项灰化，点击提示「这个房间不支持点播」。分支：想先收藏 → 操作条点「收藏」，收起，行不变。

→ 参考：[frame-3.png](imports/mock-v1/frame-3.png)（手机曲目行与迷你条）。

## Inspiration & Anti-patterns

- **借鉴——印刷曲目单**：等宽序号与时长、宋体标题、细线分隔，让结果读起来像一张排好版的歌单，而不是一堆卡片。
- **借鉴——搜索为主角**：页头宽大搜索栏，平台降为搜索栏内的「来源」，不再单独占一行。
- **拒绝——渐变光斑、毛玻璃、紫色**：典型「AI 生成感」装饰。
- **拒绝——emoji 图标**：一律自包含 SVG（现有关于页「GitHub 🔗」随改版替换）。
- **拒绝——千篇一律的白卡 + 大阴影**：层级靠细线与底色。
- **拒绝——深色主题融入平台品牌色**：前轮用户结论，平台色只做来源点。
- **拒绝——封面留黑边**：裁切填满。
- **拒绝——抄袭感**：不复刻任何现成音乐 App 的布局。
- **拒绝——手机行内堆按钮**：手机用操作条，保持列表干净（用户决策）。

## 宿站嵌入约束

只列与本设计行为直接相关的约束；其余（代理、`neteaseRequest`、样式与图标纪律、视口缩放、自动化注入等）见 AGENTS.md「Known pitfalls」与「Conventions」，不在此复述。

- **运行上下文**：插件运行在 `messages.html` iframe 内；面板是其中的全幅叠加层。
- **层级**：主面板 `z-index` 90000；播放进度浮窗 90001；批量点播进度卡 90008（挂 body，面板关闭后仍在）；收藏随机选择面板 90010；宿站弹窗与提示层 9999999 永远在上面。选集面板与收藏随机选择面板同层（90010）。**操作条与展开的底部条是主面板内部最上层**（随主面板出现，不另设 z-index 根），因而天然低于选集面板与收藏随机选择面板、低于宿站弹窗。
- **宿站弹窗**：首次注入的用户协议与残留遮罩会挡住交互；点歌台不得假设自己在最上层。
- **选集不再走宿站 `buildSelect2`**：不再需要跨弹窗 300ms 延迟，也不再需要接管宿站选项的 `onclick`；点选顺序由插件面板自己记录。
- **宿站手势**：面板内的拖动（进度轨、浮窗拖动）、滚动不得冒泡被宿站滑动手势误识别（与浮窗同一隔离方式）。
- **宿站返回键**：接管 `Utils.backward`，按 Interaction Primitives 的关闭顺序逐层关闭，不写浏览历史。
- **主题**：读宿站 `window.theme`，面板打开时写 `data-imw-theme`；面板外的浮层（批量点播进度卡）在自身节点上写 `data-imw-theme`。
- **没有 Tailwind preflight**：插件不带 preflight，`border-solid` 加单边边框会让其余三边落到浏览器默认 3px（曾在范围行、竖栏、标签栏画出粗灰框）；`app.css` base 层已补边框基线与 `border-box`，新增的面板外根节点要一并加入。
- **输入框 `@` 链接拦截**：既有路径保留，不属于点歌台界面，但与 J3 的 BV 号点播应得到同样结果；经此路径发出的点播同样写入最近点播。
- **自动播放策略**：播放需要真实用户手势——「点播」由用户点击触发，满足该要求。
- **下游——AGENTS.md 改写**：本规格取代 AGENTS.md 的「主面板颜色一律取 floating-panel 的 `themed*` 令牌」与「顶栏布局与触控目标约定（Row 1–4）」两条；改写 AGENTS.md 的 story 与第一个主面板 story 同轮完成（见 Foundation）。改写前若两者冲突，以本规格为准。

## 与浮窗的关系

〔已确认 来自 memlog，配色部分为用户决策〕

| 部件 | 何时可见 | 职责 |
| --- | --- | --- |
| 底部条 / 迷你条 / 展开的底部条 | 点歌台打开时 | 承担进度显示与跳转、「单曲循环」「收藏随机」开关 |
| 播放进度浮窗（既有，`#imw-media-progress-root`） | 点歌台关闭时（侧栏入口） | 面板外的进度与模式开关 |
| 收藏随机选择面板（既有，`#imw-shuffle-picker-root`） | 底部条或浮窗点亮「收藏随机」时弹出 | 选择随机范围；规格见 `spec-playback-loop-shuffle/shuffle-picker-panel.md` |
| 选集面板（新增，插件自有） | 多 P / 多集条目点播时 | 选分 P、正序/乱序 |
| 批量点播进度卡（新增，`#imw-batch-progress-root`） | 整张正序/乱序或选集多选确认后 | 显示批量进度、可停止；不随面板关闭消失 |

- 两处开关是同一个状态的两个入口，状态始终一致；进度跳转的权限规则两处相同，复用同一跳转逻辑。
- 收藏随机选择面板是独立根节点、非模态，层级高于主面板，所以从底部条弹出时浮在点歌台之上。
- **配色**：播放进度浮窗与收藏随机选择面板一起换成 DESIGN.md 的纸/墨/蔷薇红令牌（`components.floating-window`），取代现行天蓝强调色；结构与行为按各自既有规格不变。单独成一个浮窗改版 story。
